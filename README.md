# Caderno de Inglês

Tela do app de estudo de inglês (aulas, revisão, conversação por voz com tutor de IA e evolução).

- Esta página só contém a interface. Os dados (contas, progresso, aulas, áudios) ficam numa planilha Google, acessada pelo servidor em Google Apps Script.
- Senhas e a chave da IA nunca ficam neste repositório.
- Publicado pelo GitHub Pages a partir da branch `main`.
